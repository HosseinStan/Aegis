# Security policy

Do not report security defects in public issues. Contact the organization's
security team through its approved private reporting channel.

Never commit Aegis JWT signing keys, credential master keys, device
credentials, SSH private keys, known-host databases, configuration backups, or
production database files.

The detailed deployment assumptions are documented in
[`apps/aegis-api/SECURITY.md`](apps/aegis-api/SECURITY.md).
