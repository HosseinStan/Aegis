# Aegis v0.1.0-alpha — release notes draft

> **PRE-RELEASE · SYNTHETIC LOCAL DEMO · NOT FOR PRODUCTION**

This is an early, openly licensed development milestone for **Aegis**, a Go-based tool for controlled, read-only Cisco IOS/IOS XE configuration visibility, saved backup history, and difference review.

## What is included

- **Go REST API:** authenticated read-only configuration workflows; SSH host-key verification, protected credential fields, backup/history/diff operations and audit events.
- **Go → Node → Vue local evaluation demo:** Dashboard, device inventory, saved configuration viewer, Backup History, Side-by-side / Unified / Changes Only comparisons, and Change Review.
- **Synthetic dataset only:** four disabled mock devices across three groups; twelve disposable snapshots (three per device) stored by a separate mock-only Go entrypoint. No live switch access occurs in the demo.
- **Security/development baseline:** Go 1.26.11, GitHub CI (tests, race/static/vulnerability checks and Docker build), strict Windows Go/Node/pnpm toolchain integrity checks, verified frozen pnpm lockfile semantics, and automated synthetic Go → Node → Vue HTTP smoke.
- Apache-2.0 license, copyright NOTICE, vulnerability reporting, contribution guidance and project roadmap.

## Try the demo

Use **Windows x64**, **PowerShell 7.3+**, **Node.js 22.13+** (verified example: 24.22.1), **pnpm 11.25.0**, and the **Go 1.26.11** toolchain with verifiable integrity receipts. The launcher requires a prepared, external `local-tools.json` and prepopulated offline caches; it does not download or install software.

Follow the source-controlled instructions in [docs/DEMO.md](https://github.com/HosseinStan/Aegis/blob/main/docs/DEMO.md) and [Vue MVP README](https://github.com/HosseinStan/Aegis/blob/main/apps/aegis-ui/vue-mvp/README.md).

A successful launch prints `AEGIS LOCAL DEMO — READY` with localhost URLs. Observe 4 mock devices and 12 saved synthetic snapshots; stop with `Q` / `Ctrl+C`.

## Important limitations

**This is not production software. Phase E remains DEFERRED / NOT ACCEPTED and production release BLOCKED.**

- The public repository includes real-device API foundations, but the **demo runs only synthetic mock data**. Real-device hardware acceptance and broader Cisco platform compatibility are unverified.
- Change Review does not calculate security risk, vulnerability severity, compliance or change approval. It displays **RISK NOT EVALUATED**.
- The lab manager draft ([PR #12](https://github.com/HosseinStan/Aegis/pull/12)) and change-risk experiment ([PR #9](https://github.com/HosseinStan/Aegis/pull/9)) are not included.
- Windows launcher tools and caches must be prepared and verified by the evaluator. No signed binary, installation package or production deployment is supplied.
- No external user adoption or hardware testing numbers are claimed.
